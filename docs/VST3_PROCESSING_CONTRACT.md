# VST3 processing v1 — finite-file contract

This is a separate versioned processing job/result, not a live insert or a stock/frozen-take format change. Stock canonical formats and hashes remain untouched. A selected raw source/range and a finalized design/take WAV have explicit distinct scopes. Already finalized design/take outputs use their existing renderer and immutable receipt. Raw ambiguous/wide inputs require deliberate interpretation/subset or qualified arithmetic Mono mean; no implicit surround inference/downmix.

Only SoundPlusPlugin loads VST3 code. Each candidate scan, description/state operation and finite render runs in a supervised disposable child, one at a time. The main app and stock playback helper never load third-party modules. No plugin child opens an audio device. Scans are cached by complete bundle fingerprint; crash/hang results remain quarantined until explicit Retry. Changed bundles are rescanned. No plugin installation is performed.

A job freezes input bytes/hash and original-frame range, rate and ordered physical/layout selection; plugin class identity/version/bundle fingerprint; opaque state and hash; normalized parameter values; rate/block; explicit zero-history reset, reported latency compensation and finite tail cap; bypass and request generation. State uses independent opaque bytes, never StockEffect's numeric array. Input/plugin/parameter/tail/bypass changes invalidate Ready, cancel old admission, and require Preview. Original/Processed compares staged aligned files through shared transport, restarting each at frame zero; it is not a seamless phase-continuous switch. The processed summary identifies added tail duration. Document/context changes reject completion. Frozen sources are never rewritten.

A processing pass first restores state/parameters and negotiates exact same ordered main input/output buses (one each, no instruments/MIDI/sidechains). It resets before frame zero. It runs input plus zero extension once, discards exactly reported latency frames, and retains creative delay as content. Applied finite tail is explicit and capped, including unknown/infinite reports. Runtime latency/bus changes, non-finite output, changed input/plugin or failed publication reject Ready. Buffers are bounded by <=16 channels and <=4096 frames; duration/state/parameter/candidate/response bounds are explicit. Processing does not execute on a device callback.

Normalization and split delivery options are separate from plugin parameter Undo/Redo. A normalization toggle derives and verifies a new representation from the retained raw PCM, including validating its hash when returning to unnormalized PCM; it issues no plugin-worker request. The original processing generation/job stays attached to that pass, while the parent operation epoch prevents stale representation adoption. Input/plugin/parameter/tail/bypass edits require an explicit new Preview.

Processed float PCM is authoritative. Meter/normalization/encoding/split/copy derive from that one stage without executing the plugin again. Copy and receipts publish atomically with unique durable names after verification. A preview's processed artifact/hash, state and receipt preserve lineage, not a promise of identical future arbitrary-plugin runs. Later missing/changed plugin blocks a new run but leaves finalized WAVs usable as ordinary indexed/pool/take sources. Print uses the interleaved multichannel master, preserving masks, role order and LFE. Split member names reflect ordered roles.

Platform qualification is macOS arm64/JUCE8.0.6 only. Fixture compatibility is separate from installed vendor compatibility, human listening, physical surround and native receiving-app persistence. This paragraph describes the original v1.6 boundary. The later [isolated insert foundations](PLUGIN_HOSTING_CONTRACT.md) add VST3/AU processing and separate racks with explicit remaining limits; MIDI/instruments, sidechains and architecture bridges remain unavailable.

## v1.6.1 reliability refinements

Discovery commits a complete entries/roots snapshot atomically only after the whole scan. Cancellation escapes ordinary quarantine handlers and never replaces the last complete snapshot with partial progress. Genuine candidate failures remain cached/quarantined with explicit Retry.

Completed-pass availability is separate from the operation and delivery receipt. Copy/representation failure or cancellation reverifies completed/raw PCM on the session worker; a valid pass stays auditionable and retryable without a new plugin call. A failed/cancelled delivery has no Ready receipt. Input/settings/context changes invalidate the recovery epoch; corrupted raw authority cannot become Ready. If normalization fails, its requested checkbox and actual raw/normalized waveform label can differ explicitly. A new Preview is still an explicit new pass.

The Process panel owns audition by a unique intent ID and exact generation. Its Play/Stop and Space act on that ownership, including a pending start. A/B restarts at frame zero; completion/error/other-owner feedback comes from current shared transport state. Cancel Processing is distinct. Text/numeric editors retain Space/undo, and Stop/destruction cannot stop a different owner or capture.

Adopted input selection/scope binds independently of peak-cache content hashes. Raw workload evidence includes per-iteration ticks, search request/publication observations/status, index header operands and bounded waveform-adoption timing records. Percentiles use nearest rank, `sorted[ceil(p*N)-1]`; polling samples are not independent audio experiments.

Process opening now automatically reconciles standard system/user VST3 folders and remembered custom roots. This uses the same transactional incremental scanner: unchanged bundles reuse capabilities/quarantine, changed bundles are rechecked, and Cancel never commits partial snapshots. The chooser groups by plugin-reported category, not filename guesses, with Other effects for unclassified entries. Standard-root inputs are injectable for controlled regression folders; normal production callers use the actual macOS locations. This does not add VST2/AU hosting.

## Saved-job authority (R25)

Open uses the same background raw-first verification policy as operation recovery. A missing/corrupt normalized derivative falls back to verified raw from the same pass while retaining requested normalization; missing/corrupt raw prevents Ready. Saved delivery receipts never restore readiness: a fresh verified atomic copy is required. Historical media are not removed. Cancellation/context epochs gate adoption.

The post-R25 extension also accepts resolved AudioUnit identities in finite jobs. Discovery uses system registration and asynchronous instantiation inside the helper; AUv3 runtime qualification and required VST2 support remain open. See the hosting contract for current scope rather than assuming every discovered class is usable.
