# Agreed direction after VST3 v1.6.1

This is future work, not functionality implemented by the plugin reliability correction. The current four assignments remain a real limit; more source-pool alternatives do not create simultaneous XY assignments.

- Keep four zones by default. A zone may target a named group while preserving its layers’ relative balance.
- Allow optional additional compact XY pads for independent groups.
- Build explicit multi-target X/Y mappings on existing macros, with visible ranges, polarity and composition.
- Keep compact real waveform cards and accessible source/group labels.
- Keep surround speaker positioning separate from sound blending.
- Version performance state and recorded events; preserve exact legacy four-assignment replay.

Groups and multiple pads expand control deliberately. Arbitrary 8/16-point mixing on one pad is not currently implemented or claimed.
