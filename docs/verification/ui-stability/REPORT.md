## Stability findings

1. **Square Surround Stop.** A normal gesture-release message could reach the producer before transport Stop and finalize the pass as an ordinary release. Stop now leaves interrupted closure to the producer. The mock checks that Stop owns closure and rejects subsequent motion. The device test waits for the playback clock and checks a fresh, interrupted, paired-motion receipt against the prior pass.
2. **Native insert Undo.** Candidate B retained a first value from a new gesture under the previous native sequence. A native callback could land between polling and the message-thread snapshot. The snapshot counts a newly pending event before reading values, and it remembers those values on the same message-thread pass. The live suite verified the gesture at the Undo budget boundary, including one eviction, Undo, and Redo.
3. **AU retained owner.** Candidate B's mapped exchange contained the error `Invalid processing record`. The macOS/JUCE reproducer opened the old file, replaced it with a smaller record and read from the already-open descriptor. The path-sized reader produced invalid JSON. Reading the open stream to its bounded EOF recovered the full previous record. The hosted-instrument tests exercise repeated replacements of differently sized records and actual AU/VST3 worker handshakes.
