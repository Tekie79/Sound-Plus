# Perform layout correction

Starting HEAD bcb6c14. Perform now defaults to a **260-point macro sidebar** instead of a nearly equal-width split. The XY pad centres within the larger Blend workspace. Source cards flank its four corners when that produces a larger square; narrower windows retain the stacked four-card layout. All original waveforms, assignment targets, macro actions and mapping controls remain available.

The ten-point divider resizes both spaces. Minimums: **360 points for Blend, 240 for macros**. Left/Right adjusts by16 points (Shift:4); Home/double-click restores the default; Escape cancels an active drag. `performMacroWidth` is a workspace preference, persisted at gesture completion rather than every pixel. Shrinking a window clamps the visible width while retaining the user's preferred width for later expansion. Cancelling a clamped drag also restores that preference. Resizing does not edit the design, undo history or processing state.

Verification uses the existing performance/view/waveform/source-pool/take suites, plus targeted layout assertions across minimum, laptop and desktop view sizes. Tests cover all four cards, mapping range fields, both panel minimums, drag limits/cancel, keyboard/reset, resize preference retention and unchanged design/audio revision. This focused UI change does not alter the audio engine or take format. Native inspection and final results are recorded below.
