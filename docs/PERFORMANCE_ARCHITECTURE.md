# Performance control state — implementation design

Written before implementation against `43f5776`. This is the bounded M2 stereo blend/macros/static-snapshot slice, not recorded motion, sampler voices or a separate engine.

- **Base and controls:** each `DesignMix` owns its unchanged base layers/racks plus a versioned performance state. The original mix and each variation/snapshot therefore retain their own assignments, macro names, values and bypass flags. Entering Perform changes a workspace preference only. Assignment and mapping start bypassed; activation is explicit.
- **Resolution:** one pure `resolvePerformance` path copies the base mix, applies absolute macro targets and then blend amplitude factors, and clears the copied control state. It never writes effective values into the base. Resolving an already resolved mix is idempotent. Live parameters, graph initialization, accurate audition, offline render and selected-layer printing consume this same result. Selection printing resolves the complete mix before isolating/rebasing the primary layer.
- **Blend:** four stable-ID slots occupy top-left, top-right, bottom-left and bottom-right. Bilinear nonnegative corner coefficients are restricted to occupied slots and normalized to unit sum of squares. A single assigned layer has weight one; zero assignments do nothing. At an unoccupied corner with zero total coefficient, occupied slots get equal-power weights. Unassigned layers stay unchanged. Weights never exceed one; coherent summation can still clip, so the master/clip indicator remain explicit. Bypass restores base levels; reset centres the pad without enabling it. Gain transitions use the existing smoothed worker-side path.
- **Ownership:** one macro writer per stable parameter key, including bypassed mappings. Blend reserves assigned-layer gain from macro assignment. Targets identify layer ID, effect ID and parameter kind, never indices or names. Missing/incompatible targets remain unresolved and do nothing. Structural parameters and linked rate/pitch are excluded. The Edit inspector and canvas gain line display effective macro values. A deliberate Gain, Balance, master-gain or mapped-effect edit explicitly unlinks only that target, even when the chosen value equals its stored base. Other mapped targets remain controlled; blend weighting remains separate. The mapping editor exposes this policy. Variation locks continue to constrain random generation, not intentional performance gestures. Generation skips macro-owned parameters.
- **Macros:** four named normalized controls, individually enabled/bypassed, with reset values. Mappings store min/max, inversion and linear/logarithmic/smooth curves. Frequencies use logarithmic interpolation by default; gain is in dB, pan is signed balance, wet is a unit fraction. Suitable filter cutoffs and delay/reverb wet controls reuse the existing stock processors; coefficient changes are smoothed on the producer worker. No additional voice or graph is created by performance controls.
- **Snapshots:** Save Snapshot stores an exact base-plus-control mix using the existing named variation history, keep/discard/A-B/save/render workflow. It creates an editable kept variation: later edits while that candidate is selected change it, as they do other variations. It does not bake and then reapply controls, and is not called a take. Print-back is still a normal committed external layer.
- **Compatibility:** designs with performance state use manifest version 2 and a new stock-DSP compatibility tag; existing readers reject them instead of ignoring audio-affecting fields. Version-1 designs load with neutral defaults and keep their sound. Atomic saves, backups, recovery and receipts remain unchanged. Derived blend amplitude is serialized only for explicitly resolved intermediate documents, with the same version gate.
- **Threading and gestures:** UI values are bounded/coalesced by the existing 25 ms parameter path. JSON, resolution, file writes and DSP graph work stay off the callback; the callback still consumes prepared PCM. Gestures use session begin/end/cancel with document/variation identity gates. One drag gives one undo step; Escape restores its starting state. Edit/Perform switching never calls transport or mutates the recipe.

The implementation report records actual tests, native screenshots, measured hardware workload and remaining qualification limits. Resolve native delivery stays an independent open manual item; no drag implementation change is planned.
